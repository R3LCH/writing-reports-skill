# ГУАП: Word как основной документ, PDF из итогового DOCX

## Решение

Для совместной сдачи редактируемого DOCX и PDF предпочитать **Word-master → обновление полей → экспорт PDF**. Требование — правильное оформление и одинаковое содержание, не совпадение с LaTeX до каждого переноса. LaTeX остаётся отдельным маршрутом, когда он явно требуется или задача преимущественно ориентирована на TeX/PDF.

Нормативная основа и приоритеты: [карта стандартов ГУАП](guap-latex.md), [официальная подборка](https://guap.ru/c/regdocs/stands/uch). Проверенный учебный профиль: ГОСТ 7.32–2017, A4, 30/15/20/20 мм, Times New Roman 14 пт, Word multiple 1.5, абзац 1,25 см, чёрный текст. 14 пт — выбранный профиль, не обязательный кегль любого документа по ГОСТ. Методичка кафедры и конкретный тип работы могут устанавливать другие требования.

## Подготовка тела и титула

1. Создать **семантическое тело DOCX**, без титула и оглавления: native paragraphs, Heading 1/2/3, Word tables, изображения и OMML. Возможны python-docx, Word или Pandoc из подготовленного Markdown. Не использовать PDF → DOCX и не растрировать страницы.
2. Нумерацию разделов, таблиц, рисунков, приложений и ссылки сформировать согласованно из проверенных данных. Если номера уже включены в текст заголовков, не включать ещё одно автоматическое numbering. Формулы верхнего уровня передавать без встроенного `\tag`; сборщик размещает их номера справа. Существующие уравнения в собственных native layout tables сохраняются, смешанный вариант останавливает сборку.
3. Продолжение таблицы готовить по **реально наблюдаемым границам страниц**: над первой частью «Таблица N — …», над следующими «Продолжение таблицы N», с головкой/номерами граф. Повтор заголовков Word сам по себе не заменяет подпись продолжения. Явное разделение на части не должно менять значения или логическую нумерацию таблиц.
4. Титул — отдельный DOCX-шаблон с одной секцией, рассчитанный на одну страницу. Разместить `{{organization}}`, `{{department}}`, `{{topic}}`, `{{student}}`, `{{supervisor}}`, `{{city_year}}` либо другие имена из строчных латинских букв/подчёркиваний в абзацах или ячейках layout tables. Маркер может быть разбит на несколько runs: замена сохраняет их свойства. Исходный шаблон не изменяется. Сложные титулы/неподдерживаемые части проверять отдельно; не подменять их приблизительным восстановлением.
5. JSON fields содержит только реально предоставленные строки. Недостающие реквизиты запросить у пользователя до окончательной сборки; не выдумывать имена и не оставлять unknown-data placeholders в готовом отчёте. Placeholders допустимы только для явно запрошенного черновика; согласованное обезличивание известных данных допустимо отдельно. `reference.docx` служит стилевым образцом, не вставляет содержание готового титула.

## Сборка

Зависимости: python-docx, docxcompose (испытана 2.2.0), fontconfig с законно установленным Times New Roman; для финализации LibreOffice Writer и Python UNO. Pandoc нужен только если выбран для подготовки тела. Не раздавать Microsoft-шрифты вместе со скиллом.

```sh
# Необязательный этап; Markdown уже содержит проверенные значения и ссылки.
pandoc body.md --no-highlight -o body.docx

python3 skills/writing-reports-pandoc-gost/scripts/word_report.py \
  --body /path/to/body.docx \
  --cover /path/to/cover-template.docx \
  --fields /path/to/fields.json \
  --output /path/to/delivery/report.docx

/usr/bin/python3 skills/writing-reports-pandoc-gost/scripts/finalize_docx.py \
  /path/to/delivery/report.docx
```

`word_report.py` применяет общий профиль из `gost_docx.py` только к телу, заполняет титул без пересоздания его абзацев/таблиц, добавляет next-page section и PAGE/TOC fields. Output должен быть новым: входы не перезаписываются. Неизвестные поля, оставшиеся markers и неоднозначные варианты оглавления/формул останавливают сборку.

`finalize_docx.py` отключает макросы, обновляет оглавление, сохраняет окончательный DOCX, создаёт `report-word-layout.pdf` и обновляет checksum. В этом маршруте это **основной PDF отчёта**, а не вспомогательная копия отдельного LaTeX PDF. Допустимо дать ему имя `report.pdf` при выдаче, сохранив происхождение и checksum. Не перегенерировать PDF другим движком после проверки, не перепроверив результат.

## Нормоконтроль перед выдачей

- §6.1.1: A4, поля, чёрный текст, кегль, 1.5 и 1.25 см; математические символы и листинги могут иметь предусмотренную гарнитуру.
- §§6.2–6.4: структурные заголовки центр/прописные; разделы полужирные, с абзаца, без завершающей точки в номере; новый лист, отсутствие переносов слов/оторванных заголовков.
- §§5.4, 6.3: реальное оглавление с правильными страницами и отточиями; сквозные PAGE fields, номер внизу по центру физической страницы (не асимметричной рабочей области), скрытый номер титула, нет случайного пустого листа. Word-профиль компенсирует разницу левого и правого полей в абзаце колонтитула.
- §§6.5–6.6: ссылки, положение подписей, внешние границы, заголовки граф по центру, значения/единицы, продолжения таблиц без пропусков строк.
- §6.8: редактируемая формула по центру рабочей области, номер справа, свободная строка выше и ниже; пояснения начинаются с «где» без двоеточия.
- §§6.16–6.17: порядок и полнота источников, сохранность ссылок и записей, приложения с правильными обозначениями/наименованиями. Оформление библиографических описаний проверять по применимому стандарту и фактическим метаданным источника; одно наличие списка этого не доказывает.
- Растеризовать и просмотреть **все** страницы PDF; сверить текст, данные и native XML DOCX с исходниками. Итоговый PDF уже является рендером этого DOCX, отдельный LaTeX для такой пары не нужен.

Сохранить исходники, расчёты, изображения, original cover, fields JSON, тело DOCX, применённый профиль, команды/версии, manifest и окончательные файлы. «Идеальность» не является автоматическим свойством библиотеки; выдавать только документ с выполненными конкретными проверками.

Окончательная повторная сборка сохранена в `.omx/route-comparison/delivery/`: DOCX, его точный PDF-экспорт, исходники, использованные скрипты, manifests, `verification.json` и обзор всех десяти страниц. Дополнительно измерено положение всех девяти видимых номеров: центр совпадает с физическим центром A4 с допуском 0,5 пт.
